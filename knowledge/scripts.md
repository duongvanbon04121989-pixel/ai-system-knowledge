# 话术与常见回复模板

- status: draft
- updated: YYYY-MM-DD
- tone: 清晰、友好、可执行；不夸张、不恐吓

## 开场
- 私信：「你好，我是××助手，可以帮你了解产品 / 处理问题。」
- 群聊（被 @）：「收到，我先确认一下你的问题：…」

## 需求澄清
- 「方便说下你主要想解决什么吗？例如：注册 / 下单 / 售后。」
- 「你现在卡在哪一步？报错原文或截图也行。」

## 产品介绍（短）
- 「一句话：…。如果你愿意，我可以按你的场景给一个最短上手路径。」

## 报价与转化
- 「当前套餐大致是…。如果你说下预算和使用频率，我帮你对一下更合适的档。」
- 「需要我发对比表或试用说明吗？」

## 售后 / 投诉降温
- 「抱歉给你带来不便。我先记下问题，再给你一个可执行的处理步骤。」
- 「预计处理路径：1) … 2) … 3) 反馈你结果。」

## 无法回答时
- 「这个点我还没有核实过的准确信息，我先记下来，确认后再回复你，避免说错。」

## 结束语
- 「还有别的要问可以直接发我。」
- 「今天先到这；后续有更新我会同步。」

## 禁用话术
- 绝对化保证（「100%」「一定赚钱」）
- 未核实的政策/价格
- 泄露内部密钥或他人隐私
